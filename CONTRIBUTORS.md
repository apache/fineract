# Contributors

Thank you to everyone who has contributed to Apache Fineract!

The committers and PMC members, who review and merge pull requests, are listed on the [Apache Fineract committee page](https://projects.apache.org/committee.html?fineract).

This list follows the [All Contributors](https://allcontributors.org) specification. It shows everyone with at least 5 commits in this repository, as GitHub counts them, leaving out automated accounts. Commits whose author email isn't linked to a GitHub account can't be counted here, but they remain in the git history.

To update it, add people who reach 5 commits to `.all-contributorsrc` (for example with `npx all-contributors-cli add <github-login> code`), then run `npx all-contributors-cli generate`.
