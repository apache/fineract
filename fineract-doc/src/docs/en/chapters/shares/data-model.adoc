== Entities

=== ShareProduct

Defines the share instrument. Source: `ShareProduct`
(`fineract-shares/.../shareproducts/domain/ShareProduct.java`), table `m_share_product`.

[cols="2,1,3"]
|===
|*Field* |*Type* |*Description*

|`name` / `shortName`
|String (unique)
|Product name (≤200 chars) and short name (≤4 chars).

|`currency`
|MonetaryCurrency (embedded)
|Currency code, decimal places and multiples.

|`totalShares`
|Long
|Total authorized shares for the product.

|`totalSharesIssued`
|Long
|Shares actually issued.

|`totalSubscribedShares`
|Long
|Shares subscribed across all accounts.

|`unitPrice` / `shareCapital`
|BigDecimal
|Base unit price and total capital (`totalShares` × `unitPrice`).

|`minimumShares` / `nominalShares` / `maximumShares`
|Long
|Minimum, default and maximum shares allowed per client account.

|`marketPrice`
|Set<ShareProductMarketPrice>
|Time-based price history (effective `fromDate`).

|`charges`
|Set<Charge> (@ManyToMany)
|Charges applicable to accounts of this product.

|`lockinPeriod` / `lockPeriodType`
|Integer / PeriodFrequencyType
|Lock-in window restricting early redemption.

|`minimumActivePeriod` / `minimumActivePeriodType`
|Integer / PeriodFrequencyType
|Minimum period an account must stay active to be dividend-eligible.

|`allowDividendCalculationForInactiveClients`
|Boolean
|Whether inactive clients are still included in dividend distribution.

|`accountingRule`
|Integer (AccountingRuleType)
|Accounting treatment for the product.
|===

=== ShareProductMarketPrice

Time-based market price. Source: `ShareProductMarketPrice.java`, table `m_share_product_market_price`.

[cols="2,1,3"]
|===
|*Field* |*Type* |*Description*

|`product` |@ManyToOne ShareProduct |Owning product.
|`fromDate` |LocalDate |Date from which this price is effective.
|`shareValue` |BigDecimal |Market price per share from `fromDate`.
|===

=== ShareAccount

A client's subscription. Source: `ShareAccount.java`, table `m_share_account`.

[cols="2,1,3"]
|===
|*Field* |*Type* |*Description*

|`client` |@ManyToOne Client |Owning client.
|`shareProduct` |@ManyToOne ShareProduct |Subscribed product.
|`status` |Integer (`status_enum`) |`ShareAccountStatusType` value — see <<_data_model>> / lifecycle.
|`accountNumber` |String (unique) |Human-readable account number.
|`externalId` |String |External reference.
|`totalSharesApproved` |Long |Shares currently approved/owned.
|`totalSharesPending` |Long |Shares applied for but not yet approved.
|`currency` |MonetaryCurrency (embedded) |Account currency.
|`savingsAccount` |@ManyToOne SavingsAccount |Linked savings account where dividends are paid.
|`shareAccountTransactions` |@OneToMany ShareAccountTransaction |Purchase/redeem/charge movements.
|`charges` |@OneToMany ShareAccountCharge |Charges attached to the account.
|`lockinPeriodFrequency` / `lockinPeriodFrequencyType` |Integer / PeriodFrequencyType |Effective lock-in window.
|`minimumActivePeriodFrequency` / `minimumActivePeriodFrequencyType` |Integer / PeriodFrequencyType |Effective minimum active period for dividends.
|`allowDividendCalculationForInactiveClients` |Boolean |Inactive-client dividend flag copied from product.
|`submittedDate` / `approvedDate` / `activatedDate` / `rejectedDate` / `closedDate` |LocalDate |Lifecycle audit dates (each with the corresponding `AppUser`).
|===

=== ShareAccountTransaction

A single movement on the account. Source: `ShareAccountTransaction.java`, table
`m_share_account_transactions`.

[cols="2,1,3"]
|===
|*Field* |*Type* |*Description*

|`shareAccount` |@ManyToOne ShareAccount |Owning account.
|`transactionDate` |LocalDate |Date of the movement.
|`totalShares` |Long |Number of shares purchased or redeemed.
|`shareValue` |BigDecimal (`unit_price`) |Price per share at transaction time.
|`amount` |BigDecimal |Total amount (`totalShares` × `shareValue`).
|`amountPaid` |BigDecimal |Amount settled.
|`chargeAmount` |BigDecimal |Charges associated with the transaction.
|`status` |Integer (`status_enum`) |`PurchasedSharesStatusType`: APPLIED / APPROVED / REJECTED.
|`type` |Integer (`type_enum`) |`PurchasedSharesStatusType`: PURCHASED / REDEEMED / CHARGE_PAYMENT.
|`active` |boolean |Whether the transaction is active (not reversed/rejected).
|`shareAccountChargesPaid` |@OneToMany ShareAccountChargePaidBy |Links to charges paid by this transaction.
|===

=== ShareAccountCharge

A fee on a share account. Source: `ShareAccountCharge.java`, table `m_share_account_charge`.

[cols="2,1,3"]
|===
|*Field* |*Type* |*Description*

|`shareAccount` |@ManyToOne ShareAccount |Owning account.
|`charge` |@ManyToOne Charge |Base charge definition.
|`chargeTime` |Integer (`charge_time_enum`) |`ChargeTimeType` (e.g. share purchase, activation).
|`chargeCalculation` |Integer (`charge_calculation_enum`) |`ChargeCalculationType` (FLAT or PERCENT_OF_AMOUNT).
|`percentage` / `amountPercentageAppliedTo` |BigDecimal |Percentage and the base it applies to.
|`amount` |BigDecimal |Computed charge amount.
|`amountPaid` / `amountWaived` / `amountWrittenOff` / `amountOutstanding` |BigDecimal |Derived settlement balances.
|`paid` / `waived` / `active` |boolean |Charge state flags.
|===

=== ShareAccountChargePaidBy

Join between a transaction and the charge it settles. Source: `ShareAccountChargePaidBy.java`, table
`m_share_account_charge_paid_by`.

[cols="2,1,3"]
|===
|*Field* |*Type* |*Description*

|`shareAccountTransaction` |@ManyToOne ShareAccountTransaction |Paying transaction.
|`shareAccountCharge` |@ManyToOne ShareAccountCharge |Settled charge.
|`amount` |BigDecimal |Amount applied to the charge.
|===

=== ShareProductDividendPayOutDetails

A product-level dividend declaration. Source: `ShareProductDividendPayOutDetails.java`, table
`m_share_product_dividend_pay_out`.

[cols="2,1,3"]
|===
|*Field* |*Type* |*Description*

|`shareProductId` |Long |Product the dividend belongs to.
|`amount` |BigDecimal |Total amount to distribute.
|`dividendPeriodStartDate` / `dividendPeriodEndDate` |LocalDate |Period the dividend covers.
|`status` |Integer |`ShareProductDividendStatusType`: INITIATED / APPROVED.
|`accountDividendDetails` |@OneToMany ShareAccountDividendDetails |Per-account split.
|===

=== ShareAccountDividendDetails

A per-account share of a dividend. Source: `ShareAccountDividendDetails.java`, table
`m_share_account_dividend_details`.

[cols="2,1,3"]
|===
|*Field* |*Type* |*Description*

|`shareAccountId` |Long |Account receiving the dividend.
|`amount` |BigDecimal |Dividend amount for the account.
|`status` |Integer |`ShareAccountDividendStatusType`: INITIATED / POSTED.
|`savingsTransactionId` |Long |Savings deposit transaction created when the dividend is posted.
|`productDividentPayOutDetails` |@ManyToOne ShareProductDividendPayOutDetails |Parent declaration.
|===

NOTE: Tables, columns and relationships above are derived from the JPA mappings in the
`fineract-shares` module; refer to each entity class for the authoritative column names.
