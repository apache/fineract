= Party (Clientes, Grupos y Centros)

El módulo `fineract-party` agrupa el dominio de las *partes* a las que la institución
presta servicio: *Clientes* (`Client`), *Grupos* (`Group`) y *Centros* (`Center`),
junto con sus funcionalidades asociadas: *comisiones/cargos a clientes* (client charges)
y la *contabilidad* que estos generan (journal entries), *documentos*,
*identificaciones* (client identifiers), *direcciones* (client address),
*miembros de familia* (family members) y *transacciones de cliente* (client transactions).

El código fuente reside principalmente en `fineract-party`
(paquetes `org.apache.fineract.portfolio.client`, `...group` y `...address`).
Los orquestadores que dependen de préstamos/ahorros (creación de cuentas al activar
clientes, plantillas y hojas de cobro, asientos contables) permanecen en
`fineract-provider`; los DTO compartidos (`ClientData`, `GroupGeneralData`,
`CenterData`, `AddressData`) y las constantes de API residen en `fineract-core`.

[NOTE]
====
Un *Centro* no es una entidad propia: es un `Group` cuyo `GroupLevel` tiene
`isCenter() == true`. Comparte la tabla `m_group` y la jerarquía padre-hijo
(`parent_id`) para agrupar grupos.
====
