== Entidad `Group` / Centro (`m_group`, `m_group_level`)

Definida en `...group/domain/Group.java:63`. El discriminador Centro vs. Grupo
vive en `GroupLevel` (`m_group_level`), con `isCenter()` / `isGroup()`
(`...group/domain/GroupLevel.java:89`). La relación `parent_id` permite la jerarquía
*Centro → Grupos* y la tabla de unión `m_group_client` la membresía *Grupo → Clientes*.
